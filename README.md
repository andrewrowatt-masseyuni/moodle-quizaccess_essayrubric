# Quiz rubric settings (quizaccess_essayrubric)

Adds a *Rubrics* section to the quiz settings, controlling how the rubrics of
Essay with rubric questions are shown in that quiz. It never restricts access
to a quiz: it is an access rule plugin because that is how a plugin adds
settings to the quiz settings form and has them backed up with the quiz.

It is part of the Essay with rubric question type (`qtype_essayrubric`). See
the README of that plugin for how the plugins fit together.
